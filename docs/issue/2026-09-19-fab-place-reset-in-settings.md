# 話しかける口の居場所と高さを「既定に戻す」手を設定の画面に置くか

口の居場所と書く所の高さは DR-0002 の section 1 つ (`src/fab-place.ts`、id `fab`) として
このブラウザが覚えるが、**設定の画面 (`src/ui/Settings.tsx` の `SECTIONS`) には並べていない**。
入力が「口を掴んで動かす」「縁を引く」そのものなので、同じことを数字の欄としても置くと
触る所が 2 通りになる、という判断 (DR-0002 §2.6 に追記済み)。

## 今どうなっているか

- 置き場所を見失う事故は起きない — 覚えるのは**近い辺からの距離**で、`apply` と `settle` の
  両方で今見えている所に丸めるので、口は必ず画面の中に出る
- 「既定に戻す」手は**無い**。右下に戻したければ、人が右下へ掴んで運ぶ

## 決めること

戻す手を要るか。要るなら置き場所は 3 通り:

1. 設定の画面に section を並べ、入力は「既定に戻す」ボタン 1 つだけにする
2. 口そのものに持たせる (長押し / 右クリックのメニュー)
3. 置かない (今のまま)

2026-09-19 の裁定は「今は置かない、起票して終わり」。要るようになったら
DR-0002 §2.6 の追記ごと考え直す。
